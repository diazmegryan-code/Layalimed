# Icons

The "Browse by category" tiles on the homepage use inline SVG line icons.

- **Tabler Icons** (https://github.com/tabler/tabler-icons, MIT license, copy in `TABLER-LICENSE.txt`): `vaccine` (AV fistula needles), `vaccine-bottle` (injection & infusion), `flask-2` (concentrates), `droplets` (all hemodialysis), `shield-plus` (PPE), `bandage` (wound care), `stethoscope` (equipment), `scissors` (procedure & surgical), `pill` (medications). Stroke width was set to 1.4.
- **Original artwork** drawn for this site on the same 24px grid: dialyzer, bloodline set and dialysis catheter.
